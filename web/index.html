TWO FACES, ONE CONTROL PLANE

The client reasons. The server executes.

Use Double Agent as a pure executor, delegate an objective to its optional internal AI, or combine both approaches.

  1. DiscoverThe client finds proven capabilities over MCP.
  2. ProvisionThe scheduler selects a container, VM, CPU, or GPU.
  3. ExecuteThe isolated environment performs the work.
  4. ExportThe agent receives verified artifacts and metadata.
  5. DestroyResources are released; only approved results remain.
